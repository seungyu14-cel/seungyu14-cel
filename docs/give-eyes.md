## 프로젝트와 단계

개인의 재난 구호물품을 발송 전에 판정하고 접수처 도착까지 전달 경로를 기록하는 6인 팀의 서비스 기획입니다. 설계·프로토타입 검증 단계이며 전체 서비스의 현장 운영 완료를 의미하지 않습니다.

## 직접 담당한 기준 데이터

| 항목 | 역할 |
| --- | --- |
| 품목 코드·별칭 | 다른 표현을 표준 품목으로 정규화 |
| 차단 규칙·법적 근거 | 위험·금지 조건과 판정 이유 구조화 |
| 요금표 | 규격·무게에 따른 배송 안내 기준 관리 |

## 팀이 설계한 Agent 흐름

- 수요 Agent: 재난 공지 추출, 중복 병합, 출처 대조, 관리자 승인
- 기부 Agent: 사진 인식, 표준 품목 정규화, 규칙 판정, 무게·요금 계산, 전달 방법 분기
- 개인 접수 여부: 가능·모름·불가를 구분하고 확인되지 않은 정보를 확정하지 않음

AI 해석, 규칙 기반 판정, 사람의 승인을 구분한 설계입니다. 판단 기준 데이터 담당과 Agent 전체 구현 담당을 동일하게 표현하지 않습니다.

## 전달 기록의 범위

예약, 운송 개시, 접수처 도착의 기록을 해시로 연결하는 설계입니다. 기록 변경 탐지를 지원하며 상자 안의 실물이나 현장 배분을 자동으로 보증하지 않습니다.

팀 비공개 저장소 대신 공개 가능한 범위의 설명과 개인 기여를 정리했습니다. 기획서의 목표 수치는 실측 성과로 제시하지 않습니다.
