# FACTOFIT — 개인 기여와 개발 기록

[프로필로 돌아가기](../README.md)

## 프로젝트

제조기업의 기업·설비 정보를 활용해 투자 효과 분석, 지원사업 탐색과 신청 준비를 연결한 5인 팀 프로젝트입니다. 개인 담당은 백엔드 총괄이며 API·DB·배포·테스트와 임시 프론트 목업을 다뤘습니다.

## 직접 담당한 작업

- FastAPI·Supabase 기반 데이터와 기능 연결
- 화면에 필요한 API 응답 구조 조정
- 정책 금액·기한·자격요건·근거 문장·검증 상태 구조화
- OCR 제목 추출과 문서 카테고리 저장 관련 개발·오류 대응

## 오류를 나누어 살펴본 경험

| 관찰한 문제 | 확인한 지점 | 배운 점 |
| --- | --- | --- |
| 환경변수 누락 | 설정 로딩 경로와 필수 연결 정보 | 기능 오류와 실행 환경 오류 구분 |
| 모델 404 | 요청 모델명과 실제 설치된 모델 | 호출 대상 확인 |
| JSON 파싱 실패 | 모델 원문과 파서가 기대하는 형식 | 모델 응답 성공과 서비스 처리 성공 구분 |
| DB 컬럼 불일치 | 코드 입력 필드와 테이블 스키마 | API와 DB의 데이터 계약 확인 |

## 팀 기능과 개인 기여의 구분

LangGraph 어드바이저, ChromaDB 정책 검색, ROI 분석과 신청서 출력은 팀의 서비스 기능입니다. 이 문서가 해당 기능 전체의 단독 구현을 의미하지는 않습니다. 운영 성과나 정확도 개선율은 측정된 수치가 없어 기재하지 않습니다.
